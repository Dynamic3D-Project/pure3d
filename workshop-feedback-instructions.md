# Pure3D Feedback Workshop: Participant Instructions

**Goal:** In 30-45 minutes, try the main Pure3D workflow: browse existing content, create a collection, add an edition, upload 3D assets, fill in basic metadata, and note what is clear or confusing.

## 1. Before You Start

Use the test account provided by the workshop host. Please do not upload private, sensitive, copyrighted, or very large files.

Recommended upload set:
- **Cover image:** `.jpg`, `.png`, `.webp`, or `.avif`, under 20 MB.
- **3D model:** preferably a single `.glb` file. `.gltf`, `.obj`, and `.ply` are also accepted, but `.obj` may not show textures correctly unless companion files are included.
- **Optional Voyager scene:** `scene.svx.json`, if you already have one. This can contain camera position, annotations, tours, and scene settings.

If you do not have your own model, use the workshop sample files in `workshop-sample/`: `workshop-artifact.obj` and `scene.svx.json`.

## 2. Explore First

1. Open Pure3D and visit **Collections**.
2. Search for an existing collection or edition.
3. Open an edition and test the viewer: rotate, zoom, reset view, open annotations/tours if available, and try the description/metadata tabs.
4. Write down one thing you understood immediately and one thing that felt unclear.

## 3. Create a Collection

1. Go to **Collections**.
2. Click **+ New Collection**.
3. Add a clear title, for example: `Workshop Test - Your Name`.
4. Upload a collection image if you have one.
5. Add short descriptive metadata: creator, institution, subject, place, language.
6. Leave visibility off unless the workshop host tells you to make it visible.
7. Click **Save Changes**.

## 4. Add an Edition

1. Open your new collection.
2. Click **+ New Edition**.
3. Add an edition title and authors.
4. Upload a cover image.
5. In **3D Model Files**, upload your main model. Best test: a `.glb` file with embedded textures. If using `.obj`, also upload any companion `.mtl` and texture files.
6. If you have a Voyager scene file, upload it under **Scene file (SVX)**. Otherwise, continue with only the model file.
7. Wait for the upload progress to finish and check whether the preview loads.
8. Try replacing or removing a file, then upload it again.

## 5. Describe the Edition

1. In **Description**, write a 2-3 sentence abstract explaining the object and why it matters.
2. Add 3-5 **Tags / Keywords**.
3. In **Metadata**, fill in at least: subtitle, contributors, institution, subjects, place, language, rights holder, and license.
4. In **Review**, tick **Request peer review** only if the host asks you to test the review workflow.
5. Click **Save Changes** or **Draft Proposal**.
6. Click **View Edition** and check whether the public-facing page matches what you entered.

## 6. Feedback Questions

Please answer these after the exercise:
- What did you expect to happen when creating a collection or edition?
- Which labels or buttons were unclear?
- Did the upload instructions make sense? Which file types did you try?
- Did the 3D preview load? If not, what file did you upload and what message did you see?
- Was the difference between a collection, an edition, a model file, and an SVX scene clear?
- What would stop you from using this for your own 3D material?

Thank you. Please keep your test collection and edition in draft form unless the workshop host asks otherwise.
